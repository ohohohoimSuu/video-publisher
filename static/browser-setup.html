先启动本机发布台

如果网页已显示“工作区已就绪”，可以直接跳到首次安装扩展。

  1. 下载并解压本机运行包

    得到 video-publisher 文件夹。把它放到自己方便管理的位置；程序运行期间请保留这个文件夹。

  2. 准备 Python，并安装依赖

    电脑需要 Python 3.11 或 3.12。打开文件夹中的 setup.command，等待依赖安装完成。首次安装需要联网下载运行环境。

  3. 启动发布台

    打开 启动发布台.command。它会打开本机网页。使用期间保持这个终端窗口运行，再返回本网站连接 Chrome。

这是需要本机运行环境的测试包，尚不是免安装的独立桌面 App。每位使用者的数据保存在自己的电脑；下载包不含其他人的账号、视频或任务记录。

首次安装 Chrome 扩展

  1. 下载扩展并解压

    点击上方“下载 Chrome 扩展 0.4.1”。解压后得到 video-publisher-chrome 文件夹。若下载的是本机运行包，也可以直接使用里面的 chrome-extension 文件夹。

  2. 打开 Chrome 扩展管理页

    在平常登录平台的那个 Chrome 用户配置中，把 chrome://extensions/ 输入地址栏并按回车，再开启右上角“开发者模式”。

  3. 加载文件夹

    点击“加载已解压的扩展程序”，选择刚解压的 video-publisher-chrome 文件夹。选中后应该能在文件夹里看到 manifest.json；不要选择 ZIP 文件，也不要只选择某个 JS 文件。

  4. 确认名称和版本

    扩展卡片应显示“本地视频发布台 · 普通 Chrome 上传”，版本 0.4.1，开关处于启用状态。Chrome 会说明所需权限，其中“调试”权限用于操作任务新开的平台页面。

装对版本的标志

点开扩展后，看到“配对已经内嵌到发布台”和“断开连接”。日常使用不需要填写连接码，也不需要打开这个弹窗。

已经装过旧版？这样升级

旧版：登录同步

显示“一次性连接码”“同步当前平台登录”。它只同步会话，不能完成新版网页连接。

新版：普通 Chrome 上传

版本 0.4.1，显示“配对已经内嵌到发布台”。在发布台网页中点击“连接 Chrome”。

  1. 下载并解压新版

    使用本页的 0.4.1 下载按钮。仅刷新发布台网页，不会更新 Chrome 中已经加载的旧扩展。

  2. 停用旧的“登录同步”扩展

    在扩展管理页关闭旧扩展的开关，避免之后误点。不要改动其他无关扩展。

  3. 加载新版文件夹

    点击“加载已解压的扩展程序”，选择本次解压的 video-publisher-chrome 文件夹。确认显示版本 0.4.1，再刷新发布台网页。

如果你明确用新版文件覆盖了原来加载的同一个文件夹，也可以点击该扩展卡片的“重新加载”。没有替换文件时，重新加载旧卡片仍然是旧版。

回到网页，连接并测试

  1. 确认本机发布台正在运行

    网页应显示“工作区已就绪”。如果没有，先启动本机运行包中的 启动发布台.command。

  2. 点击“连接 Chrome”

    在安装了扩展的同一个 Chrome 中刷新发布台网页，然后点击“连接 Chrome”。配对自动完成，不用复制连接码。

  3. 先测试打开三个平台

    显示“普通 Chrome 已连接”后，点击“测试打开三个平台”。这个按钮只打开 B站、抖音和小红书页面，不选择文件、不上传、不发布。

连接成功后，日常操作只留在发布台

选视频和平台 → 上传并填写 → 在平台页面检查内容 → 自己点击发布。平台要求登录或手机验证时，在对应页面完成。

遇到问题，先检查这里

已经安装，网页仍提示没有扩展

确认扩展是 0.4.1、已启用，并装在当前打开发布台的同一个 Chrome 用户配置中。刷新网页后再点“连接 Chrome”；如果弹窗仍有“一次性连接码”，请按旧版升级步骤操作。

显示“无法连接本机服务”

扩展不能代替本机运行包。启动本机发布台并保持终端窗口运行；浏览器询问是否允许本网站连接本机服务时，请按自己的使用意愿决定是否允许。

为什么没有 Chrome 商店的一键安装按钮？

当前是测试版，尚未发布到 Chrome 网上应用店，使用“加载已解压的扩展程序”安装。安装包从本网站直接下载，不依赖任何人的电脑或登录状态。

会操作我原来打开的标签页吗？

组件只接入本次任务新开的平台页面。平台登录继续保存在当前 Chrome；组件不申请 Cookie 读取权限，也不会点击最终发布。

支持范围与测试进度

当前普通 Chrome 路线面向 B站、抖音和小红书。代码和本机通信检查已通过，真实平台完整上传仍在验收中。不要把“页面能打开”当作“上传填写已全部通过”。封面失败时可在保留的页面手动处理，本版尚不支持普通 Chrome 的自动封面续接。
